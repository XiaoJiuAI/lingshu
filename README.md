# 灵枢 2.0.2

本地运行的 AI 长篇小说写作工作室。从故事设定、分卷大纲、季章规划到逐章生成与优化，全程在本地完成；数据保存在本机，API Key 由用户自行配置。

## 快速开始

1. 下载并解压 `灵枢2.0-Windows-x64.zip`
2. 进入解压后的文件夹，双击 **`灵枢2.0.exe`**
3. 首次使用：进入顶部 **「设置」**，填写 [DeepSeek](https://platform.deepseek.com/) API Key，点击「测试连接」
4. 返回 **「作品」**，点击「新建」开始创作
5. 按步骤条依次完成：**设定 → 大纲 → 规划 → 写章 → 完结**

> 没有 API Key 也可创建作品、手动编辑内容，但无法调用 AI 功能。

---

## 功能概览

| 模块 | 说明 |
|------|------|
| **设定** | 输入梗概，AI 生成世界观、角色、修炼体系等，确认后才写入 |
| **大纲** | 按卷组织故事结构，支持手动编辑与 AI 优化 |
| **规划** | 先定季、再拆章，生成本卷章节要点 |
| **写章** | 多 Agent 流水线生成本章初稿，支持 AI 优化（确认才写入） |
| **完结** | 查看全书进度，通读正文 |

## 系统要求

- 建议 8 GB 及以上内存
